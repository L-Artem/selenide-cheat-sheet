Hamcrest помогает писать тесты. Не надо путать его с полнофункциональными фреймворками для тестирования, такими как JUnit.
Hamcrest – это всего лишь библиотека matcher-ов, которая используется в паре с JUnit или другим аналогичным фреймворком для тестирования.
В Hamcrest вся функциональность переложена именно на matcher-ы, такие как equalTo(), not(), anyOf(), is().
Их много, и они разного предназначения: логические, для тестирования объектов и бинов, для тестирования строк, чисел, коллекций.
А предикат assertThat() всего один, именно он используется для тестирования всех объектов.
